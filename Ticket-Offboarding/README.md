# Ticket 004 — Employee Offboarding

## Overview
Simulated an employee offboarding request using Microsoft 365 and Spiceworks.

## Tasks Completed
- Blocked user sign-in
- Revoked active sessions
- Removed user from the Finance Department security group
- Reviewed mailbox for important business emails
- Granted HR read/manage access to the mailbox
- Preserved access to the user's OneDrive files
- Verified important company data could be accessed
- Documented and closed the help desk ticket

## Tools Used
- Microsoft 365 Admin Center
- Microsoft Entra ID
- Exchange Online
- OneDrive
- Spiceworks

## Skills Demonstrated
- User lifecycle management
- Access management
- Account security
- Data preservation
- Help desk ticket documentation
