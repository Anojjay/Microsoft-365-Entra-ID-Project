# Ticket 1 — Slow Computer

## Scenario
User reported that their computer was running slowly.

## Troubleshooting
- Reviewed CPU and memory usage in Task Manager
- Checked disk performance
- Reviewed startup applications
- Disabled an unnecessary startup application
- Restarted the computer

## Resolution
System performance was checked and the ticket was closed after troubleshooting.

## Tools Used
- Windows Task Manager
- Spiceworks
